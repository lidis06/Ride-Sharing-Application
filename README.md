# Ride-Sharing-Application
This project is a Java-based desktop application designed to simulate a ride-sharing and airport transfer booking service developed as part of my University Group Project.

Project Category: University Group Project
Language: Java
Framework: Swing
Purpose: Demonstrating object-oriented programming, desktop application development, booking management, and software integration.
The application brings together several components of a booking system, including journey selection, estimated pricing, booking management, promotional deals, payment information entry, and booking confirmation.

The project was designed to provide practical experience in developing a multi-component application using Java and object-oriented programming principles.

Working on this project provided opportunities to strengthen my understanding of software development, graphical user interface design, data handling, and the integration of independently developed components into a larger application.

My Individual Contributions

As part of this university group software development project, I was personally responsible for developing two key components of the Java ride-sharing application: the Booking System and the Amend Booking functionality.

1. Booking System Development

I developed the booking functionality using Java and the Swing GUI framework, allowing users to create and manage airport transfer bookings.

My implementation included:

Designing an interactive booking interface using Java Swing components.

Allowing users to select airport destinations, travel dates, times, and luggage quantities.

Implementing a pickup location input field.

Developing the Booking class to represent individual bookings.

Using BookingService to manage bookings through an ArrayList.

Implementing a simplified journey duration calculation based on luggage quantity, pickup location, and simulated traffic conditions.

Integrating the booking functionality with the application's shopping cart.

This component strengthened my understanding of object-oriented programming, data structures, event-driven programming, and graphical user interface development.

2. Amend Booking Functionality

I also developed the functionality that allows users to modify existing bookings without having to create an entirely new reservation.

My implementation included:

Creating an interface displaying existing bookings through a dropdown selection menu.

Implementing date and time selectors using Java Swing's JSpinner and SpinnerDateModel.

Allowing users to update the date and time of a selected booking.

Checking for scheduling conflicts against other bookings stored in the cart.

Displaying feedback messages when amendments are successful or when a selected time slot is unavailable.

Implementing logic that adjusts journey durations for other bookings associated with the same airport.

Refreshing the booking selection interface to reflect updated booking information.

This functionality provided valuable experience in data validation, updating existing records, conditional logic, and maintaining consistency between application data and the user interface.
